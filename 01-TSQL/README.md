# 01 - T-SQL

This chapter builds query fluency before moving into administration. The exercises use an `Employees`-style dataset and progress from filtering to reusable query patterns.

## Sections

- [SELECT](./SELECT) - projection, filtering, ordering, NULL handling, and subqueries
- [JOIN](./JOIN) - INNER, LEFT, and SELF JOIN patterns
- [GROUP-BY](./GROUP-BY) - aggregates, grouping, and HAVING
- [CTE](./CTE) - readable multi-step queries with Common Table Expressions
- [Window-Functions](./Window-Functions) - ranking, running totals, and period comparisons

The last two sections are being expanded; existing exercises are kept runnable while new examples are added.
